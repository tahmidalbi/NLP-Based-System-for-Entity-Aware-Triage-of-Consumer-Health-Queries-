# Install with:
#   pip install -r requirements.txt
#
# Notes:
# - torch is pulled from PyTorch's CUDA 12.1 wheel index (line below) so it
#   installs with GPU support where a CUDA 12.x-compatible driver is present;
#   pip falls back to the plain PyPI index for every other package.
# - The official `fasttext` PyPI package fails to build on Windows against
#   modern pybind11/MSVC (pybind11 API changes broke its 0.9.3-era C++
#   bindings). `fasttext-wheel` is a maintained fork of the same underlying
#   C++ library with prebuilt wheels and an identical `fasttext` import name/
#   API - use it instead, not both.
--extra-index-url https://download.pytorch.org/whl/cu121
