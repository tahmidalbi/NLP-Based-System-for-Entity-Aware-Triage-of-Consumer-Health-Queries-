\# Bangla Healthcare Severity Dataset



\*\*Version:\*\* 1.0



\## Overview



The Bangla Healthcare Severity Dataset is a manually annotated Bangla healthcare text corpus developed for healthcare Natural Language Processing (NLP) research.



The dataset contains \*\*5,263\*\* real-world Bangla healthcare-related queries collected from publicly accessible Facebook and YouTube discussions. Each sample has been manually annotated into one of four healthcare severity classes: \*\*Emergency\*\*, \*\*Urgent\*\*, \*\*Routine\*\*, and \*\*General Query\*\*.



This dataset supports research in low-resource Natural Language Processing, medical text classification, healthcare AI, clinical decision support systems, and transformer-based language models.
